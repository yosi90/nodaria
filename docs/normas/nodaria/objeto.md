Nodaria es una web para organizar ideas como un mapa de nodos y relaciones. Tú defines los tipos, sus atributos y cómo se conectan, y con ellos construyes tus proyectos: una novela, una investigación, un sistema o una base de datos.

Estas normas valen para todo lo que haces en Nodaria, y sobre todo para los proyectos que publicas.
